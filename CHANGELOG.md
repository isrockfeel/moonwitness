# Changelog

All notable changes to MoonWitness are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Releases are generated by [Release Please](https://github.com/googleapis/release-please) from
Conventional Commit messages. Do not edit released sections by hand.

## [0.2.0](https://github.com/isrockfeel/moonwitness/compare/v0.1.0...v0.2.0) (2026-11-11)

### Features
* **a11y:** skip link + landmark main di semua route
* **a11y:** target sentuh 44px, cincin fokus global, aria-current nav
* **assets:** artwork shadow-command + aktifkan tes keberadaan sumber
* **assets:** enam artwork zine baru untuk landing, pipeline, dan collections
* **assets:** manifest artwork + pipeline sharp avif/webp 480-1920
* **atmosphere:** lapisan p5.js + p5.brush agar UI lebih hidup
* **avatars:** sistem avatar witness berbasis DiceBear dan ID Lab
* **command-center:** ganti Mission Control dengan Shadow Command Center
* **fonts:** ganti Google Fonts dengan keluarga proprietary Saksi
* ORM framework implementation with magic fields, actor context, addon system
* **types:** paket tipe domain, data app berhenti mendeklarasikan tipe
* **ui:** primitif zine dan komposit status dashboard
* update API layer with timeline persistence and avatar system

### Bug Fixes
* **lint:** pulihkan pemuatan konfigurasi ESLint frontend
* **ui:** guard reduced-motion CountUp + target sentuh >=44px pada mobile

### Performance
* **web:** path artwork lewat manifest + tuning optimizer gambar
