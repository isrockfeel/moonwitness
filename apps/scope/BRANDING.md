# Scope Branding

## Identity

**Name**: Scope
**Tagline**: _see the signal, scope the work._
**Meaning**: Dual-meaning — oscilloscope (radio signal) + engineering scope (project scope).

## Color Palette

| Token        | Hex       | Usage                            |
| ------------ | --------- | -------------------------------- |
| `base`       | `#0f172a` | App background (slate-900)       |
| `surface`    | `#1e293b` | Cards, panels (slate-800)        |
| `border`     | `#334155` | Borders (slate-700)              |
| `text`       | `#e2e8f0` | Primary text (slate-200)         |
| `text-muted` | `#94a3b8` | Secondary text (slate-400)       |
| `accent`     | `#34d399` | Pass, online, live (emerald-400) |
| `warn`       | `#fbbf24` | Blocked, drift (yellow-400)      |
| `danger`     | `#f87171` | Fail, offline (red-400)          |
| `info`       | `#60a5fa` | Info (blue-400)                  |

## Typography

- **Font**: Monospace (ui-monospace, SFMono-Regular, Menlo, Consolas)
- **Rationale**: Developer tool — code, hashes, and commit messages render in monospace.

## Iconography

- **Logo**: Oscilloscope waveform → gate/checkmark hybrid
- **App icon**: Green sine wave on dark background (`#0f172a`)
- **Status indicators**: Colored dots (emerald = pass/online, red = fail/offline, yellow = blocked)

## Voice

- Direct, technical, no fluff.
- Exit codes and states are first-class: PASS, FAIL, BLOCKED, NOT APPLICABLE.
- No fake green — a blocked state is shown as blocked, not hidden.
